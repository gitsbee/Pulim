# 풀림 (Pulim) 통합

풀림·수학·영어는 기존 Pages 주소 아래에서 같은 상단 바와 Firebase 계정을 사용한다. 풀림의 담벼락에는 기존 게시물·댓글·리포스트를 그대로 표시한다.

## 코드 구성

- `src/learning/`은 서비스 전환과 프로필, 계정별 풀이 기록 화면, 이전 온라인 랭킹 조회을 구현한다.
- `public/study/palette.css`는 문제공방에서 가져온 공통 팔레트와 조작 요소를 담는다. 풀림과 영어 화면에서 불러오며, 문제공방은 원본 CSS를 사용한다.
- 원본 `mathforge-v153.html`과 `ankimaster.html`에서 HTML·CSS·스크립트를 분리해 과목별 학습 도구로 포함했다. 수학 문제 생성·채점·그래프·필기와 영어 단어장·학습 모드를 유지하기 위해 각 과목의 연습 DOM은 프레임 안에서 실행한다. 프레임에는 로그인 폼이 없으며, 부모 앱이 원래 상단 바에 서비스 전환과 프로필을 넣고 계정별 저장 공간을 지정하며 채점 이벤트를 수집한다. 양쪽은 전송 출처와 상대 프레임을 확인한다.
- 문제공방의 오늘의 문제는 수학의 원래 학습 화면과 문제 생성기를 사용한다. 이전 공통 문제의 결과와 공개 점수에 대한 데이터 경로는 호환을 위해 유지한다.

## 데이터와 운영

| 위치 | 내용 | 공개 범위 |
| --- | --- | --- |
| `users/{uid}/learning/{id}` | 과목·문제명·학습 방식·결과·시각 | 본인 |
| `users/{uid}/learningDays/{day}/subjects/{subject}/answers/{index}` | 오늘의 문항별 첫 결과 | 본인 |
| `pulleemDays/{day}/subjects/{subject}/scores/{uid}` | 사용자가 공개를 선택한 정답 수 | 전체 |

서버 규칙은 한국 날짜, 문항 번호, 최초 제출, 소유권과 세 문항의 합계를 검사한다. 정오 판정은 브라우저에서 수행하므로 랭킹은 참여용으로 운영한다. 계정의 풀이 요약과 오늘의 결과를 연동하며, 초안·필기·과목 내부의 복습 상태는 이 브라우저에 보존한다.

Firebase 콘솔에서 `firestore.rules`를 게시한 다음 Pages 배포 결과를 확인한다. 운영에서는 두 브라우저에서 같은 계정으로 로그인해 새 풀이 기록이 양쪽에 나타나는지 확인한다.
